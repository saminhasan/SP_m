Data is all in the following format:
n x 8 matrix named "data_mtl"

The columns are the following:
Time (s) | X Linear Acceleration (m/s^2) | Y Linear Acceleration (m/s^2) | Z Linear Acceleration (m/s^2) | X Angular Velocity (deg/s) | Y Angular Velocity (deg/s) | Z Angular Velocity (deg/s)

The X, Y, and Z directions are the following:
X is anterior/posterior (pointing anteriorly - towards the chest) on the upper back
Y is medial/lateral (pointing right lateral) on the upper back
Z is superior/inferior (pointing superiorly) on the upper back

Note that this is not the raw data, but data that has been rotated to the above frame.
